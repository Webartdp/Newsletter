# Імпорт підписників

1. Відкрийте вкладку **Підписники**.
2. Натисніть **Імпорт CSV/TXT**.
3. Завантажте файл до 10 МБ.
4. Перевірте попередній перегляд і виберіть колонки Email та Ім’я.
5. Оберіть поведінку для наявних email.
6. Запустіть імпорт і перегляньте підсумковий звіт.

## Підтримувані варіанти

- CSV із комою, крапкою з комою, табуляцією або вертикальною рискою;
- TXT з одним email у рядку або з розділеними колонками;
- UTF-8 та Windows-1251;
- файл із заголовками або без них.

Приклад розміщено у `docs/examples/subscribers.csv`.

Відписані підписники не активуються автоматично, якщо користувач явно не ввімкнув відповідну опцію. Заблоковані підписники не активуються імпортом.
