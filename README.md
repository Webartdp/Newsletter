# DnepritNewsletter

Компонент email-розсилок для MODX Revolution 2.8.1.

## Реалізовано

- стандартна структура MODX Extra;
- xPDO-схема для підписників, кампаній, черги та журналу;
- сервісний клас компонента;
- CMP-контролер і пункт меню;
- transport package builder;
- resolver для створення таблиць;
- серверний список підписників із пошуком і фільтрацією;
- додавання та редагування підписників через ExtJS-вікно;
- перевірка й нормалізація email;
- захист від дублікатів;
- активація, відписка та блокування;
- групова зміна статусу й масове видалення;
- імпорт підписників із CSV/TXT;
- автоматичне визначення роздільника та підтримка UTF-8/Windows-1251;
- попередній перегляд і вибір колонок Email/Ім’я;
- пропуск або оновлення дублікатів;
- опціональна повторна активація відписаних;
- підсумковий звіт імпорту;
- список email-кампаній із пошуком і фільтрацією;
- створення, редагування, копіювання та видалення чернеток;
- візуальний HTML-редактор і окрема текстова версія листа;
- налаштування відправника та Reply-To;
- блокування редагування кампанії після підготовки до відправлення;
- український і російський інтерфейс.

## Формати імпорту

Підтримуються файли `.csv` і `.txt` розміром до 10 МБ за замовчуванням. Для CSV автоматично визначаються кома, крапка з комою, табуляція або вертикальна риска. TXT без роздільників обробляється як один email у кожному рядку.

Максимальний розмір файлу налаштовується системним параметром:

```text
dnepritnewsletter.import_max_size
```

Тимчасові файли зберігаються в `core/cache/dnepritnewsletter/imports/`, недоступні з публічної директорії та автоматично видаляються після імпорту або через 24 години.

## Плейсхолдери листа

У темі, HTML-версії та текстовій версії можна використовувати:

```text
[[+name]]
[[+email]]
[[+unsubscribe_url]]
[[+site_name]]
```

Заміна плейсхолдерів буде виконуватися на етапі формування персональної черги відправлення.

## Вимоги

- MODX Revolution 2.8.1;
- PHP 7.4+;
- MySQL/MariaDB;
- ExtJS 3.4 / MODExt.

## Збірка пакета

1. Розмістіть репозиторій у корені тестової установки MODX або передайте шлях через змінну середовища `MODX_BASE_PATH`.
2. Запустіть:

```bash
php _build/build.transport.php
```

Готовий transport package буде створено у стандартній директорії пакетів MODX: `core/packages/`.
